# Кряк-при 🦆

Пинбол 3D для выбора ведущего дейлика. Впишите до восьми имён, отметьте присутствующих и нажмите «Запустить мультибол». Список и отметки участия сохраняются в этом браузере. Можно включить звук и сразу запустить следующий раунд.

Игра открывается на главной странице `/`; прежний адрес `/pinball/` ведёт на ту же игру. Других игровых режимов и переключателя нет.

## Карта «Глубина»

Единственная карта состоит из трёх этажей: «Реактор», «Турбина» и «Ядро». Первые две лунки продолжаются открытыми желобами и вылетом на следующую площадку. Каждый шарик проходит уровни отдельно; побеждает первый, прошедший обе промежуточные лунки и упавший в третью.

Все игроки начинают из покоя в одном ряду на одинаковой высоте. Перед полем расположена широкая разгонная площадка без поперечного уклона. Единая физическая заслонка удерживает весь ряд, затем одновременно открывает проход. Случайного разброса начальных скоростей и положений нет. Имена независимо перемешиваются по стартовым местам, фазы механизмов меняются каждый раунд. Имена физике не передаются, повторные победы возможны.

Rapier 3D рассчитывает столкновения с CCD и шагом 1/240 секунды. Пол, борта, желоба и механизмы используют общую геометрию для изображения и физики. Пружины действуют только при опоре и имеют ограниченный импульс; роторы движутся физически. Между этажами шарики падают по настоящим желобам.

Камера плавно перемещается между этажами, сохраняя угол и масштаб. Цвета, имена и этаж каждого участника показаны в списке под полем. Нужен WebGL 2; скрытая вкладка приостанавливает игру. Учитывается момент пересечения лунки внутри физического подшага.

После 95 секунд пружины отключаются, все механизмы останавливаются и поднимаются. На 180-й секунде сохранён явно обозначенный резервный выбор по пройденному этажу и расстоянию до финальной лунки. Аварийный выход за дальние границы учитывается отдельным счётчиком и возвращает шарик на старт с первого уровня.

Физические серии, команды измерений и исторические проверки пинбола — в `docs/pinball-verification.md`. Внутренние геометрии прежних полей пинбола сохранены для регрессионных проверок; в игре доступна только «Глубина».

## Запуск

Node.js 22.13 или новее:

```sh
npm install
npm run dev
```

Проверки:

```sh
npm test
npx tsc --noEmit
npm run build
npm run build:pages
node --experimental-strip-types scripts/measure-pinball-descent.mjs 8 1000 8
```

## Сборки

Исходники хранятся в [ArtemiyShisha/quack-prix](https://github.com/ArtemiyShisha/quack-prix). Репозиторий [quack-prix-play](https://github.com/ArtemiyShisha/quack-prix-play) предназначен для готовой браузерной сборки GitHub Pages.

`npm run build:pages` создаёт `dist/pages/`: HTML для `/` и `/pinball/`, минифицированные JS/CSS и изображение утки. Файлы из этой папки, включая `.nojekyll`, можно публиковать в корень ветки `main` репозитория `quack-prix-play`. Исходные TS/TSX, серверные сборки, карты исходников и файлы окружения туда не попадают. Статическая и серверная сборки используют одну игру.

Автономный Node.js-вариант запускается командами `npm run build` и `npm start`. Он слушает `PORT` (по умолчанию 3000) на `HOST` (по умолчанию `0.0.0.0`). `Dockerfile` и `railway.json` сохранены для отдельного развёртывания. Прежний Sites-вариант доступен через `npm run dev:sites`, `npm run build:sites` и `npm run start:sites`.

## Устройство

- `lib/pinball-reactor.ts`, `lib/pinball-descent.ts`, `lib/pinball-maps.ts` — общая геометрия поля, этажей и механизмов.
- `lib/pinball.ts`, `lib/pinball-arenas.ts` — инициализация Rapier, столкновения, старт и финиш.
- `lib/pinball-arena-scene.ts`, `lib/pinball-materials.ts`, `components/pinball-table.tsx` — изображение, камера и список участников.
- `components/duck-game.tsx`, `hooks/use-race.ts` — состав, отсчёт, пауза, результат и повторный старт.
- `lib/roster.ts`, `lib/random.ts` — сохранение состава и независимая жеребьёвка.
- `lib/race.ts`, `lib/track.ts` — общие типы состояния, длительность отсчёта и палитра участников.
- `tests/pinball*.test.ts`, `tests/roster.test.ts`, `tests/random.test.ts` — физические проверки, состав и случайность.

Спрайт утки создан для проекта, цвета меняются при отображении. Список команды не отправляется на сервер. Совместный вход с разных устройств отложен.
