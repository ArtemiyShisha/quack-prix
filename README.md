# Кряк-при 🦆

Одна длинная трасса, до восьми уток и случайный ведущий дейлика.

Впишите имена, отметьте присутствующих и нажмите «Выпустить уток». Имена сохраняются локально в браузере, отдельно для каждого адреса сайта. Ориентир — около 30 секунд, но это не дедлайн: утки финишируют по физике. В проверенной серии типичные заезды занимали 22–30 секунд плюс трёхсекундный отсчёт; иногда получается быстрее или дольше. Можно включить звук и посмотреть всю трассу.

## Запуск проекта

Нужен Node.js 22.13 или новее.

```sh
npm install
npm run dev
```

Адрес появится в выводе сервера. Для проверки и сборки:

```sh
npm test
npx tsc --noEmit
npm run build
```

## Трасса

Пять разных участков: развилка с двумя скатами, подвижные пинбольные бамперы, два турбо-каскада, волновой бассейн и последний каскад с развилкой и вертушкой. Бамперы отбрасывают уток, а подсвеченные водяные ускорители дают толчок по направлению стрелок. Волна начинает набираться после прибытия первой утки. Пока течение перемешивает стаю, следующие участники могут догнать лидера; затем вода выходит поочерёдно через левый и правый шлюзы. Рисунок препятствий и физика используют общую геометрию.

## Случайность

Имена независимо перемешиваются по физическим телам алгоритмом Fisher–Yates. Для равномерного выбора индекса используются `crypto.getRandomValues` и rejection sampling, а для каждой физической симуляции создаётся отдельный случайный seed. От него зависят стартовые смещения, толчки, движение вертушек и бамперов, фаза шлюзов и всплески турбо. Имена и порядок списка не участвуют в расчётах физики. Победителя заранее нет; повторные победы допускаются.

Тела имеют одинаковые размеры, массу, трение и упругость. Шаг физики фиксирован — 1/60 секунды. При нескольких финишах за один шаг сравнивается доля шага, на которой пересечена линия; точная ничья решается независимым от имён порядком физических мест.

На 50-й секунде «Большой смыв» открывает препятствия для всех. Если никто не добрался к 60 секундам, выбирается утка с наибольшим продвижением вниз, с явной подписью «Победа по дистанции». Скрытая вкладка приостанавливает время гонки. На слабом устройстве реальное время может быть больше времени симуляции.

Математическое равенство шансов следует из независимого равномерного распределения имён по телам, даже если одна физическая дорожка удобнее другой. Небольшая серия заездов не обязана давать поровну побед.

## Устройство

- `lib/race.ts`, `lib/track.ts`, `lib/wave-pool.ts` — физика, геометрия и общий цикл волнового бассейна.
- `lib/random.ts`, `lib/roster.ts` — случайность и проверка списка.
- `hooks/use-race.ts` — отсчёт, пауза, фиксированный шаг и повторные заезды.
- `components/race-track.tsx` — SVG-поле с движущейся камерой.
- `app/page.tsx` — список команды и экран победителя.
- `tests/` — проверки жеребьёвки, физики и защитного завершения.

Используется [Matter.js](https://brm.io/matter-js/) 0.20.0. Спрайт утки создан специально для этого проекта; цвета меняются только при отображении. Приложение не отправляет список команды на сервер. Одновременное участие с разных устройств пока не реализовано.
