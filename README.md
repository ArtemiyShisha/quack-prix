# Кряк-при 🦆

Одна длинная трасса, до восьми уток и случайный ведущий дейлика.

Впишите имена, отметьте присутствующих и нажмите «Выпустить уток». Имена сохраняются локально в браузере, отдельно для каждого адреса сайта. Ориентир — около 30 секунд плюс трёхсекундный стартовый отсчёт, но это не дедлайн: утки финишируют по физике. Случайные залпы могут заметно ускорить или продлить гонку. Можно включить звук и посмотреть всю трассу.

## Запуск проекта

Нужен Node.js 22.13 или новее.

```sh
npm install
npm run dev
```

Адрес появится в выводе сервера. Для проверки и сборки:

```sh
npm test
npx tsc --noEmit
npm run build
```

## Трасса

Пять разных участков: развилка с двумя скатами, кряко-пинбол, два турбо-каскада, бешеный водоворот и последний каскад с развилкой и вертушкой. Примерно каждые 1–1.4 секунды по всей трассе проходит случайный залп: одних уток подбрасывает вверх, других разгоняет вниз, всех бросает вбок. Сила и направление выбираются заново для каждого физического тела. Вспышки и стрелки показывают толчки, а плашка сообщает тип события: гейзеры, боковая волна или турбо-лотерея.

Вертушки на залпах меняют скорость и могут развернуться. Пять подвижных бамперов сильно отталкивают уток, а водяные ускорители на скатах толкают по стрелкам. Водоворот непрерывно меняет направление; между подвижными шлюзами всегда остаётся широкий выход. Вязкий участок и накопление волны убраны. Рисунок препятствий и физика используют общую геометрию.

## Случайность

Имена независимо перемешиваются по физическим телам алгоритмом Fisher–Yates. Для равномерного выбора индекса используются `crypto.getRandomValues` и rejection sampling, а для каждой физической симуляции создаётся отдельный случайный seed. От него зависят стартовые смещения, толчки, движение вертушек и бамперов, фаза шлюзов и всплески турбо. Отдельный поток псевдослучайных чисел выдаёт новые залпы на протяжении всей гонки. Имена, порядок списка и текущие места не участвуют в выборе толчков. Победителя заранее нет; повторные победы допускаются.

Тела имеют одинаковые размеры, массу, трение и упругость. Шаг физики фиксирован — 1/60 секунды. При нескольких финишах за один шаг сравнивается доля шага, на которой пересечена линия; точная ничья решается независимым от имён порядком физических мест.

На 50-й секунде «Большой смыв» открывает препятствия для всех. Если никто не добрался к 60 секундам, выбирается утка с наибольшим продвижением вниз, с явной подписью «Победа по дистанции». Скрытая вкладка приостанавливает время гонки. На слабом устройстве реальное время может быть больше времени симуляции.

Математическое равенство шансов следует из независимого равномерного распределения имён по телам, даже если одна физическая дорожка удобнее другой. Небольшая серия заездов не обязана давать поровну побед.

## Устройство

- `lib/race.ts`, `lib/track.ts`, `lib/wave-pool.ts`, `lib/chaos.ts` — физика, геометрия, проточный водоворот и случайные залпы.
- `lib/random.ts`, `lib/roster.ts` — случайность и проверка списка.
- `hooks/use-race.ts` — отсчёт, пауза, фиксированный шаг и повторные заезды.
- `components/race-track.tsx` — SVG-поле с движущейся камерой.
- `app/page.tsx` — список команды и экран победителя.
- `tests/` — проверки жеребьёвки, физики и защитного завершения.

Используется [Matter.js](https://brm.io/matter-js/) 0.20.0. Спрайт утки создан специально для этого проекта; цвета меняются только при отображении. Приложение не отправляет список команды на сервер. Одновременное участие с разных устройств пока не реализовано.
