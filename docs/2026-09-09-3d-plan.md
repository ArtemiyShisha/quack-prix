# 3D marble mode

Add `/3d` alongside the preserved classic `/` route, with shared roster, attendance, identity shuffle, sound, result and repeat controls. The new mode uses actual three-dimensional rigid spheres under gravity. A raised open trough winds downhill, widens around an island, passes bumpers and a moving paddle, enters a funnel, and drops onto a finish chute. One shared mesh supplies rendering and static collision surfaces. Three.js renders perspective, shadows, support legs, rotating marbles and projected name/duck talismans. A follow camera and whole-course view keep the game legible. Missing WebGL offers the classic route.

Implement shared mesh data and a deterministic Cannon simulation, then renderer and route integration. Preserve independently shuffled names and derive the winner from physical finish crossing. No rank forces or recurring random impulses. Target roughly half a minute without a forced 30-second result. Validate 1–8 bodies, collisions, changing trajectories, deterministic seeds, finite states, natural completion and timing, plus TypeScript/build and independent read-only review. Publish to existing owner-private Site and sync the user's project. Browser visual QA is outside the request.
