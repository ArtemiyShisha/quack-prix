# Проверка первой версии

- 14 автоматических проверок: равномерный выбор индекса, перестановки, воспроизводимость, свежие seeds, состав, дубликаты, повреждённое хранилище, пересечение финиша, все составы 1–8, неизменность результата, вынужденная остановка и резервное завершение, точная ничья.
- Независимый просмотр исходников проверил фиксацию состава на заезд, повторный запуск, паузу, геометрию и отделение личности от физики.
- Обычные заезды на четырёх уток в первоначальном наборе 25 seeds: 22.1–29.1 секунды, среднее 25.8. На восьми: 19.4–25.8, среднее 22.5. Редкие заезды, особенно с одним участником, требуют смыва после 32 секунд.
- Добавлены необязательные WebMCP-команды для состава, старта и чтения результата. Текущий предпросмотр не предоставляет зарегистрированные команды через WebMCP; проверка их контракта в браузере недоступна. Они не требуются для работы обычного интерфейса.
- Отдельная визуальная проверка и клики браузером не выполнялись: пользователь их не запрашивал. Поле показывалось в непрерывном локальном предпросмотре.
