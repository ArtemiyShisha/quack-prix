# Проверка чаш-воронок — 8 сентября 2026

Прошёл 21 тест и проверка TypeScript. Проверены: неизменная плавная сила в свободном движении без событий по таймеру; реальное движение по орбите; изменение траектории при контакте; постоянно открытые выходы; геометрия соединений; отсутствие столкновений под полом; восстановление массы и контактов после перехода; порядок входа в желоб внутри шага; естественный финиш после 30 секунд; состав 1–8; независимая жеребьёвка; воспроизводимость seed; неизменность результата и аварийное завершение.

Независимый просмотр выявил два связанных дефекта: перестановку почти одновременных входов и нарушение интервала на входе в желоб. Исправления используют интерполяцию пересечения круглого выхода, неизменное время прихода и очередь в вертикальном участке под полом. Повторный просмотр подтвердил, что более поздний участник не обходит уже ожидающего, а интервал сохраняется. Регрессионный тест воспроизводит финишную ситуацию с двумя входами за один шаг.

## Серия из 200 гонок

По 25 seeds 1000–1024 на каждый состав 1–8. Серия выполнена на итоговой физике после исправления входов. На каждом шаге проверены конечность координат, скоростей, углов и прогресса, границы поля и чаш, предел времени. Все заезды завершились обычным финишем. Общий смыв и резервный выбор по дистанции не потребовались.

Время симуляции не включает три секунды стартового отсчёта. Скорость — единицы поля за шаг 1/60 секунды, по наблюдениям каждые 0.1 секунды после первой секунды, только для тел на поверхности. Доля наблюдений со скоростью меньше 1 составила 0.93–1.26% в зависимости от состава. Утки двигаются по чашам, а не стоят у закрытого выхода.

Количество в одной чаше — размер наибольшей группы в момент измерения; оно не означает, что все участники всегда рядом с лидером. Для восьми уток лидер находился в чаше как минимум с половиной команды в 68.03% измерений, в которых он сам был на поверхности; для четырёх — в 84.04%. Короткие переходы по желобам исключены из этой доли.

## Изменение порядка

Для каждой из чаш 2–4 сравниваются первый вошедший и первый вышедший. На четырёх участниках они различались в 46.67% случаев; на восьми — в 69.33%. Первый вошедший в третью чашу выиграл всю гонку в 44% и 24% заездов соответственно. Это изменения фактического порядка прохождения, а не частые переключения подписи лидера из-за колебаний радиуса.

Серия описывает наблюдаемое поведение модели, не гарантирует обгон в каждом заезде и не доказывает равенство шансов имён. Равномерное независимое распределение имён по одинаковым телам проверяется отдельно.

Повторить из корня проекта:

```sh
node --experimental-strip-types scripts/measure-course.mjs 25 1000
```

## Границы

Локальная страница с новой трассой скомпилировалась и вернула HTTP 200. Браузерные клики, скриншоты и визуальная проверка не выполнялись: пользователь их не запрашивал. Проверка движения выполнена на данных симуляции. Модель чаш двумерная, соединительные желоба задают движение вдоль линии; это описано в README. Редкие отрывы, дополнительные круги и повторные победы допустимы. На медленном устройстве реальное время может быть больше времени симуляции; скрытая вкладка приостанавливает её.
