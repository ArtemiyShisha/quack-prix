# Проверка концовки — 8 сентября 2026

`npm test`: 23 проверки пройдены. `npx tsc --noEmit` и `npm run build`: успешно. Независимый просмотр исходников не нашёл проблем; дополнительно проверены 200 гонок на seeds 3000–3049 для составов 1/2/4/8, отсутствие выхода из закрытого бассейна, численная устойчивость и фиксация результата. Проверены общий цикл волны, его однократный старт по физическому прибытию, чередование выходов, реальные положения шлюзов и частые смены победителя относительно лидера третьего этапа. Остались проверки списка 1–8, случайности, одинаковых физических тел, ударов и турбо, паузы на уровне исходников, пересечения финиша, неизменности результата и защитного завершения.

Все 1650 гонок (основные 1200 плюс отдельные 450) завершились физическим финишем. Выбор по дистанции не потребовался. На каждом шаге проверялись конечность координат/скоростей/углов, боковые границы и аварийная граница времени. Восемь одиночных гонок потребовали общего смыва. Медиана числа уток, достигших бассейна к первой волне: 2 из 4 и 4 из 8.

30 секунд — приблизительный ориентир. Общий смыв возможен после 50 секунд, явно подписанный резервный выбор по дистанции — после 60. Полностью искусственно заблокированный заезд отдельно подтверждает оба механизма и фиксацию результата. Скрытая вкладка останавливает симуляционное время.

## Ограничения проверки

Визуальная проверка и клики браузером не выполнялись: пользователь их не запрашивал. Команды WebMCP и обычные действия списка/старта не менялись; ранее подтверждены регистрация, чтение состояния и отказ запуска без участников. Поведение на каждом устройстве не проверялось: слабое устройство может показывать гонку дольше времени симуляции.
